# Pocket-Dimensions

プレイヤーごとの専用区画に移動し、区画内の出口から元の場所へ帰還できる Minecraft 1.20.1 / Forge 47.4.0 以降向けの単体 MOD です。

## 遊び方

発動キー（既定は **P**）を押し、40 tick の詠唱が終わると専用区画に移動します。入口の紫色の帰還ゲートから一度離れ、そのゲートに入り直すと発動地点に戻ります。帰還後はすぐに次の詠唱を始められます。

Minecraft の「設定」→「操作設定」→「キー割り当て」で発動キーを変更できます。「ソーシャルインタラクション」と同じキーの場合は入室操作が優先されます。両方を使う場合は片方のキーを変更してください。

マルチプレイではサーバーと参加クライアントの両方に本 MOD を入れます。

## ビルドとテスト

Java 17 を使い、Windows では `.\gradlew.bat build`、macOS / Linux では `./gradlew build` を実行します。JAR は `build/libs/` に生成されます。サーバー側の自動テストは同じコマンドの `build` を `runGameTestServer` に置き換えると実行できます。

仕様と受け入れ条件は[要件定義書](docs/requirements.md)を参照してください。参照用の JAR はローカルの `reference/` に配置します。
