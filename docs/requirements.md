# Pocket-Dimensions 要件定義書

初版の要件案 · 2026-11-21

## 目的と対象環境

Iron's Spells 'n Spellbooks の Pocket Dimension 呪文の効果を、単体 MOD で利用できるようにする。プレイヤーは自分専用の小区画へ移動し、建築や保管を行い、区画内の出口から発動地点へ帰還できる。

- 初版は Minecraft Java Edition 1.20.1、Forge 47 系、Java 17 を対象とする。シングルプレイと Forge 専用サーバーに対応し、マルチプレイではサーバーと参加クライアントに本 MOD を導入する。[Forge 公式ドキュメント](https://docs.minecraftforge.net/en/1.20.1/gettingstarted/)
- 必須要素は Minecraft、Forge、本 MOD とする。魔法書、マナ、呪文レベル、他の呪文、参考 MOD のワールドからのデータ移行、他 MOD 専用の連携は初版の対象外とする。

## 参考 JAR から確認した挙動

`reference/irons_spellbooks-1.20.1-3.16.4.jar` のメタデータ、クラス、構造データを静的に確認した。

| 項目 | 確認内容 |
| --- | --- |
| 発動 | 戦闘中とポケット次元内では詠唱を開始できない。詠唱時間は 40 tick、既定の呪文クールダウンは 60 秒。発動するとプレイヤー本人が直接移動する。 |
| 区画 | 一つのポケット次元にプレイヤーごとの区画を確保する。プレイヤー UUID と区画 ID が保存され、区画は 256 ブロック間隔で割り当てられる。構造テンプレートは幅 16 × 高さ 32 × 奥行き 16 ブロックで、境界・空気・床・出口を含む。 |
| 帰還 | 発動元のディメンション、座標、水平の向きを記録し、区画内のポータルに接触すると発動元へ戻れる。 |
| 設置制限 | 参照 JAR の設置制限用タグにはベッド、リスポーンアンカー、一部の他 MOD の転送設備などが含まれる。 |

静的確認のため、ポータルの有効時間や、再接続・再起動後の挙動は実機で未確認。以下の表は本 MOD で満たす要件を記載する。部屋の見た目、構造データ、テクスチャ、音声、コードは本 MOD 用に作成する。

## 初版の機能要件

| ID | 項目 | 要件 |
| --- | --- | --- |
| F-01 | 発動 | 再利用可能な専用アイテムを右クリックで 40 tick 使用すると、サーバーが本人を専用区画へ直接転送する。途中で使用をやめた場合や転送に失敗した場合はクールダウンを開始しない。成功後の再使用には 60 秒のクールダウンを設ける。 |
| F-02 | 発動条件 | 戦闘中、専用次元内、クールダウン中は入室を拒否し、理由をプレイヤーに表示する。戦闘状態は Minecraft の戦闘トラッカーに従い、使用開始時と転送直前に判定する。 |
| F-03 | 区画の生成と所有権 | 同じワールドではプレイヤー UUID ごとに一つの専用区画を初回入室時に生成する。以後の入室で同じ区画を使い、同時入室でも区画の割り当てが重複しない。通常プレイでは他人の区画へ入れず、ペット・乗り物・ドロップアイテムを入退室時に転送しない。 |
| F-04 | 区画内の利用 | 区画内で通常のブロックの設置・破壊、コンテナの利用ができる。境界と出口は通常プレイで破壊・移動できない。専用次元では自然スポーンを無効にし、ベッドとリスポーンアンカーの設置を禁止する。 |
| F-05 | 帰還 | 入室が成功するたびに直前のディメンション、座標、水平・垂直の向きを記録する。区画内の出口に接触すると、記録した地点へ帰還する。滞在時間は無制限とし、出口にクールダウンを適用しない。入室直後の接触では帰還せず、一度出口から離れて再接触すると有効になる。 |
| F-06 | 帰還先の安全性 | 記録座標が塞がれているなど安全に立てない場合は、安全に立てる近傍の位置を探す。元のディメンションが利用できない場合や近傍に安全な位置がない場合は、オーバーワールドの安全なワールドスポーン付近へ帰還させ、理由を表示する。帰還に失敗した場合は記録を保持し、再試行できるようにする。 |
| F-07 | 保存と復元 | 区画の割り当て、ブロックとコンテナの状態、滞在中プレイヤーの帰還先をワールド単位で保存する。区画内で切断した場合やサーバーを通常停止・再起動した場合も、再接続後に区画の利用と帰還を継続できる。区画内で死亡した場合は通常の死亡・リスポーン処理を適用し、次回入室時に新しい帰還先を記録する。 |
| F-08 | 転送失敗時の扱い | 区画や転送先を用意できない場合は現在の場所に留め、理由を表示する。初回生成の再試行や復元で既存の区画を上書きしない。 |

## 受け入れ条件

| 検証 | 期待結果 |
| --- | --- |
| Forge に本 MOD のみを追加してシングルプレイと専用サーバーで起動する | どちらの環境でもワールドへ参加でき、入退室できる。 |
| オーバーワールドとネザーでそれぞれ発動し、出口を使う | 40 tick の使用完了で本人が移動する。出口に再接触すると元のディメンションの座標と向きに戻り、持ち物が維持される。 |
| 使用を途中でやめるか、戦闘中・区画内・クールダウン中に発動を試す | 入室条件を満たすまで転送されない。成功済みのクールダウンは早期終了せず、帰還には影響しない。 |
| 二人が同時に初回入室し、区画ごとに異なる目印とチェストを置く | 二人に別々の区画が割り当てられ、再入室時も各自の目印とチェストの中身が残る。通常プレイで他人の区画へ渡れない。 |
| 区画内で建築し、境界や出口の破壊・移動、ベッドやリスポーンアンカーの設置を試す | 建築可能な場所では通常のブロックを設置・破壊でき、境界と出口は維持される。ベッドとリスポーンアンカーの設置は拒否される。 |
| 区画内でログアウトし、サーバーを通常停止・再起動して再接続する | 元の区画とチェストの内容が保持され、出口から発動地点へ帰還できる。通常時は 60 秒を超えて滞在しても帰還できる。 |
| 区画内で死亡後、リスポーン地点から再入室する | 通常のリスポーンが行われ、出口は新しい発動地点につながる。 |
| 滞在中に帰還地点を塞ぐか、元のディメンションを利用できない状態にする | 安全な近傍またはオーバーワールドの安全な地点に帰還でき、代替地点への案内が表示される。 |
| 区画の生成や帰還を意図的に失敗させてから復旧する | プレイヤーは転送前の場所に留まり、原因が通知される。復旧後に再試行でき、既存の建築・保管物が維持される。 |

## 初版の暫定値と未決事項

- 発動方法は再利用可能な専用アイテムを暫定採用する。アイテムの名称とサバイバルでの入手方法は未決定。
- 区画の外寸は参考 JAR と同じ幅 16 × 高さ 32 × 奥行き 16 ブロックを暫定値とする。建築できる内寸、初期配置、ポータルの外観・演出は実装前に決める。
- クールダウンを切断・再起動後にも引き継ぐか、帰還先の近傍をどこまで探索するかは未決定。
